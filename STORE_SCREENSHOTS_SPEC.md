## General Style Guidelines

### Visual Consistency:
1. **Gmail Theme**: Use Gmail's default light theme (most recognizable)
2. **Color Palette**:
   - Primary: Gmail's blue (#1a73e8) for accents
   - Warning: Orange/amber (#FF9800) for notifications
   - Success: Green (#34a853) for "after" states
   - Text: Dark gray (#202124) for readability
3. **Typography**: Use Gmail's default font (Roboto or similar sans-serif)
4. **Notification Style**: Chrome's native notification design (rounded corners, shadow)

### Technical Requirements:
- **Dimensions**: 1280x800 pixels (preferred) or 640x400 pixels
- **Format**: PNG or JPG (PNG preferred for text clarity)
- **Aspect Ratio**: 16:10 (1280x800) or 8:5 (640x400)
- **Corners**: Square (no rounded corners)
- **Padding**: None (full bleed - content goes to edges)
- **File Size**: Optimize for web (under 500KB per screenshot recommended)

### Content Guidelines:
1. **Minimal Text Overlays**: Keep text overlays to 1-2 words or short phrases
2. **Realistic Content**: Use believable email content (not lorem ipsum)
3. **Professional Context**: All emails should appear business/professional
4. **Clear Focus**: Each screenshot should have one clear message
5. **No Blur**: All text should be crisp and readable
6. **Consistent Branding**: Use SendSafe branding consistently (shield icon, color scheme)

### What to Avoid:
- ❌ Too much text in overlays (overwhelming)
- ❌ Blurry or pixelated images
- ❌ Rotated or skewed screenshots
- ❌ Inconsistent Gmail UI (use current Gmail design)
- ❌ Fake or unrealistic email content
- ❌ Cluttered compositions
- ❌ Inconsistent notification styling
- ❌ Screenshots that don't match the extension's actual behavior

### Testing Checklist:
- [ ] All screenshots are 1280x800 or 640x400 pixels
- [ ] Square corners, no padding
- [ ] Text is readable when scaled down to 640x400
- [ ] Gmail UI looks current and realistic
- [ ] Notifications match Chrome's native style
- [ ] Email content is professional and believable
- [ ] Consistent color scheme across all screenshots
- [ ] No blur or distortion
- [ ] Branding is consistent
- [ ] Each screenshot tells a clear story
